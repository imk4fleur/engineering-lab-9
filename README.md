# Практическая №9: анализ энергопотребления зданий

Веб-приложение загружает CSV, считает статистику расхода, строит распределение и график среднего расхода по температурным диапазонам, обучает классификатор и оценивает его на отложенной части. Демонстрационный набор содержит синтетические данные.

## Запуск

Из корня проекта:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

Откройте <http://127.0.0.1:5000>, скачайте пример CSV, выберите файл и нажмите «Анализировать и обучить модель». Затем в форме «Прогноз для здания» введите температуру от −100 до 100 °C и целое число людей от 0 до 1 000 000. Результат показывает вероятность высокого расхода и класс при пороге 50%, а не число кВт·ч.

CSV: UTF-8, запятая, заголовки `outside_temp` (наружная температура °C), `occupants` (число людей), `energy_kwh` (расход за сутки, кВт·ч), `high_usage` (метка 0 или 1). Значения должны быть конечными числами; число людей и расход — неотрицательными. Нужно минимум 10 строк и оба класса в обучающей части. Предел загрузки — 256 МБ; дополнительные столбцы игнорируются. Старые демонстрационные файлы без `energy_kwh` не подходят — скачайте или создайте новый файл; приложение их не перезаписывает.

Демоданные синтетически моделируют потребление: температура и число людей влияют на расход, а метка `high_usage` равна 1 при расходе от 80 кВт·ч. Порог задан для демонстрации. Для внешнего CSV метка берётся из файла; согласованность метки и расхода не проверяется.

## Как это работает

Pandas читает CSV блоками по 10 000 строк; загруженный файл временно сохраняется на диск и удаляется после обработки. Границы диаграмм вычисляются по всему набору, затем подсчитываются значения в каждой порции: графики показывают **все строки**. Если все значения одинаковы, для диапазонов используется ширина 1 единица. График температуры показывает среднее потребление в диапазоне, а не отдельные измерения.

Каждая пятая строка — проверочная, остальные — обучающие. `StandardScaler` вычисляет параметры только на обучающей части, затем `SGDClassifier` обучается порциями по двум признакам: температуре и числу людей. Расход и метка не используются как признаки, чтобы не раскрывать ответ модели. На проверочных строках вычисляются accuracy, precision, recall, F1 и матрица ошибок; если метрику вычислить нельзя, отображается «не определена». При упорядоченных данных разбиение может не отражать реальное распределение; качество модели зависит от состава и порядка данных.

После обучения модель и нормализатор хранятся в памяти одного процесса. Новая успешная загрузка заменяет модель; старая вкладка при попытке прогноза попросит обучить модель заново. После перезапуска необходимо снова загрузить CSV. Значения за пределами диапазона обучающего набора отмечаются как менее надёжные.

## Большой демонстрационный файл

Из корня проекта создайте миллион синтетических строк. Команда не перезапишет существующий файл:

```bash
.venv/bin/python generate_demo.py demo-energy-1m.csv --rows 1000000
```

Загрузите `demo-energy-1m.csv` на странице. Генератор и обработчик работают порциями; файл должен быть не больше 256 МБ. Используйте новое имя, если файл с таким именем уже существует.
